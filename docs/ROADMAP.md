# Roadmap

Aligned with the PRD (§11). This boilerplate ships the MVP scope; the
next releases layer on top.

## V1.1

- Social login (Google/GitHub) — configurable, disableable
- Two-factor authentication (TOTP + recovery codes)
- Custom roles & permission editor per organization
- Notification preferences
- Coupon management (admin)

## V1.2

- Outbound webhooks: endpoint registration, signing, delivery logs, retries
- Expanded audit-log UI (filter, export)
- S3-compatible storage guide + quota integration
- Usage alerts near thresholds

## V1.3

- Second billing provider adapter
- Localization + multi-currency display
- Richer API reference

## V2

- Custom domains / white-label options
- Referral & affiliate capabilities
- Advanced usage billing (overages)
- Admin impersonation (audited, guarded)
